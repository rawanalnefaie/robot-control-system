# Robot Control System

## Project Overview

This project is a simple web-based control system for a robot. It provides five buttons to control the robot's movement: Forward, Backward, Left, Right, and Stop.

When a button is pressed, the command is sent to the PHP server and stored in a MySQL database. Each command is saved as a single letter.

## Features

* Forward movement
* Backward movement
* Left movement
* Right movement
* Stop command
* Store the current command in a MySQL database

## Commands

| Button   | Stored Command |
| Forward  | `f`            |
| Backward | `b`            |
| Left     | `l`            |
| Right    | `r`            |
| Stop     | `S`            |
